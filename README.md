# Credit Card Fraud Detection

## Overview
This project detects fraudulent credit card transactions using the Isolation Forest algorithm. It is an unsupervised machine learning model designed for anomaly detection.

## Technologies Used
- Python
- Scikit-learn
- Streamlit
- Pandas
- NumPy

## Features
- Fraud transaction prediction
- Unsupervised anomaly detection
- Streamlit web interface
- PCA-based preprocessing

## Model Used
- Isolation Forest
